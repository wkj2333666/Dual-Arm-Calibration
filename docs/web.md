# 网页工作台

安装后运行：

```bash
dual-arm-calibration web --port 8765 --data-dir runs/web
```

在浏览器打开 `http://127.0.0.1:8765`。网页资源随 Python 包分发，无需 Node 或前端构建步骤。

## 已提供

- 标定流程：说明左右手眼、顶相机桥接、独立验证，以及可选内参和桌面步骤。
- 接入配置：适配器、设备身份、连接和板规格的空白草稿，可保存和恢复。
- 离线验证：运行合成示例，可选择桌面步骤；也可上传匹配的 rig.json 与 observations.json。
- 标定结果：显示求解状态、失败原因、公共坐标系与独立验证偏差，可下载 JSON 或 ZIP 数据包。

导入数据中的可选步骤以其 rig 配置为准。网页草稿不会覆盖导入配置。
结果下载只导出记录，不会替换已安装标定；正式发布仍通过 CLI 的 publish 入口完成。
已保存的任务在重启服务后仍可查看。运行中退出的任务会标记为中断失败，需重新提交。

## 数据目录

接入草稿为 `integration-draft.json`，每次任务有独立目录和 job.json，成功后生成 run/ 数据包。
本地配置可能包含设备地址，`runs/` 默认被 Git 忽略。使用仓库外的自定义数据目录时，
也应保持其为本机运行数据，不作为项目源码提交。

服务用于本机操作，默认监听 127.0.0.1；尚未提供远程登录和多用户任务管理。

## 深度与双目标定（可选）

`--depth-config` 指向本机 JSON，至少包含 `serial` 和与实物核对的 `board`。
默认不加载深度 SDK、不连接相机。可选参数：

- `target_pairs`：30；`min_corners`：12 个左右共同角点。
- `stable_s`：0.25 秒；`stable_rms_px`：左右视图各自相对窗口起点的角点 RMS 位移不超过 1.5 像素，与原有停稳采集规则一致。
- `novelty_px`：相对任一已有样本，共同角点中位位移至少 25 像素。
- `duration_s`：默认 300 秒自动结束；界面显示本轮倒计时及停止原因，停止始终保留已保存样本。
- `camera_service` 与 `camera_status_file`：可选的本机 systemd 用户相机服务及其状态文件。
  状态需有 `wall_time`、`recording`；确认未录像后暂停，结束时恢复。

这些是可调整的采集参数，不是厂家精度保证。调用者负责让机器人静止，并避免其他相机
使用者并发打开设备。驱动放在独立子进程中，停止请求不阻塞网页。默认只监听本机；
局域网监听须由现场显式指定，网页未提供用户认证。

每个采集目录保留配置、左右图、RGB、原生深度、共同角点及 IR 帧信息。
当前未保存 RGB 帧号和时间戳；停稳判定仅覆盖左右 IR，尚未检查 RGB–IR 时间一致性。
具体证据及下次采集待办见[验证记录](validation.md#2026-11-07红外与-rgb-时间一致性待核查)。
只接收左右帧号相同且时间戳差不超过 1 ms 的 IR 对。该条件不意味着 RGB 硬件同步；
板需停稳。红外小图案可二倍插值辅助检测，角点映射回原始像素坐标。
检测启用 OpenCV 的板结构辅助标记恢复（`tryRefineMarkers`），以恢复远处未直接解码的标记候选；
仍使用共同角点与停稳规则。采集须覆盖实际工作距离，近距离样本不能替代桌面远距离验证。

“继续采集”创建新批次并复制已有样本，原批次保持不变；核对相机、板规格和图像参数后补拍。
去重也包含原有样本。若要在目标已满后补采，请在现场配置中提高 `target_pairs` 后续采。

最少 25 组，其中至少 5 组留出。页面报告跨视图重投影误差、极线残差、基线和候选矩阵。
离线对照可用 `python -m dual_arm_calibration.stereo SESSION --fixed-k-radial2`：固定厂家
`fx/fy/cx/cy`，仅拟合每路红外的 `k1/k2`，再拟合双目旋转和平移。`p1/p2/k3` 固定为零，
训练/留出划分与默认方案相同。请为对照使用独立实验目录，保留已有结果。
固定的是输入相机 K；校正后虚拟相机的 P 矩阵仍由 stereoRectify 根据裁剪和共同视场计算。
保留候选而不发布，独立高度验证另做。结果中的视差必须与对应输出分辨率的焦距配套；
二次校正后的点需通过 R1 的逆旋转返回原左相机坐标，再使用外参计算世界高度。
开始或继续采集会启用浏览器提示音，也可单独点击试音；每次保存响两声。刷新后需要重新开启。
声音从访问网页的电脑播放，页面会显示音频暂停状态；系统或网站静音仍需在浏览器端检查。

### 离线拟合红外到 RGB 的外参

`python -m dual_arm_calibration.color_extrinsics --session SESSION --reference METADATA --output NEW_DIRECTORY`
复用采集中的 RGB 图及共同板角点；`METADATA` 显式提供既有 RGB 内参、畸变、世界变换和厂家
`color_from_left`，不得补成设备默认值。固定 RGB 模型和世界基准，仅拟合 IR 到 RGB 的刚体变换。
沿用双目标定训练/留出 ID；独立板高不参与优化。对比已拟合的 IR 模型、相同 K 且残余畸变为零、
厂家 IR 模型，报告正反方向留出投影误差。零畸变分支用于敏感性分析，不是完整双目重标定。

Y8 红外是已校正图像，拟合的畸变仅描述残余修正，不能再次套用原始传感器镜头系数。
目前旧批次未保存 RGB 帧时间戳，未验证 IR/RGB 的时间一致性；停稳采集有助于减小影响，但不能证明
完全同步或已经发生错配。输出保持候选状态，需要独立图像、板高验证，不自动写入固件或真机配置。

### 固定 K 的联合拟合

先在独立目录完成 `--fixed-k-radial2` 及红外到 RGB 外参拟合，再运行：
`python -m dual_arm_calibration.joint_stereo --source FIXED_K_SESSION --output NEW_DIRECTORY`。
联合优化左右红外的 `k1/k2`、左右红外外参、左红外到 RGB 外参及每个训练姿态的板位姿。
三台相机的 K、RGB 畸变、板尺寸、RGB 到世界变换保持固定，损失为三路图像的像素残差平方和。
训练与留出 ID 不变，不剔除误差大的留出姿态；留出观测不进入优化。
报告收敛状态、三路训练误差和分别预测右 IR／RGB 的留出误差；三路训练 RMS 不应与
之前仅双目的训练 RMS 直接比较。仍须独立测量板高，不能凭拟合误差下降发布参数。

### 使用已应用标定的 FFS 推理

2026-11-07 经操作者授权，固定 K 联合候选已应用到 H100 SSH 别名对应主机的 FFS 服务。
这是服务端按相机序列号选择的几何校正，不是模型重新训练。未写入相机固件，抓取接口仍使用
原生深度；既有 RGB 标定和桌面基准未变。新采图像的验证结果见[验证记录](validation.md)。

服务端加载 `/home/wkj/ffs-service/calibration/active.json`，校正模块为
`ffs_profile.py`（与本仓库同名模块相同）。当前 profile ID 为
`top-d435i-joint-fixed-k-20261107`，仅用于序列号 `262922070766` 的 1280×720 SDK Y8 红外图。
profile 保存 `image_size`、`stereo`（K/D/R1/R2/P1/P2）、`color_from_left`、
`world_from_rgb`、`table_z_m`，以及来源记录。参数保存在本机运行数据中，不随源码公开分发。

先通过 SSH Bridge 转发服务端口 18080，然后使用客户端（安装 depth 可选依赖）：

```bash
python -m dual_arm_calibration.ffs_client \
  --url http://127.0.0.1:18080 \
  --left /absolute/path/left.png --right /absolute/path/right.png \
  --serial 262922070766 --width 960 --output /absolute/path/result.npz
```

客户端默认向 `/infer` 发送 `calibration=active` 和 `camera_serial`，可在 Python API 中传入
精确 profile ID 以固定版本。服务拒绝不匹配的序列号/输入尺寸和标定模式下手动覆盖的
fx、baseline、cx；未传 calibration 的旧请求保持原行为，不能假定旧调用者自动应用新标定。

服务先在完整输入分辨率下校正，再缩放、推理。重建使用与输出尺寸配套的 P1/P2，
包含主点差和缩放的像素中心变换，之后用 R1 逆旋转回原左 IR 坐标，经过 IR→RGB→世界
变换得到桌面上方高度。不额外拟合或减去高度偏移。
输出 NPZ 的 `depth_m` 是新校正左相机轴向深度；`xyz_left_m` 是原左 IR 坐标；
`height_above_table_m` 是米制桌面高度。`valid` 只表示视差有限且几何上有效，不是置信度或遮挡判断。
`metadata` 记录所用标定及坐标系；消费端须核对，不可再套厂家 IR→RGB 外参重复转换。

部署前服务源码备份在远端 `/home/wkj/ffs-service/backups/pre-calibrated-20261107/server.py`。
需要回退时，先保留当前源码及 active.json，再用该备份恢复 `/home/wkj/ffs-service/server.py`，
执行 `systemctl --user restart ffs-inference.service` 并检查 `/health`。旧服务不读取新 profile；
标定模式客户端应停止使用，改回原调用路径。此回退不改变相机固件或机器人配置。
