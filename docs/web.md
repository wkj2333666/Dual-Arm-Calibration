# 网页工作台

安装后运行：

```bash
dual-arm-calibration web --port 8765 --data-dir runs/web
```

在浏览器打开 `http://127.0.0.1:8765`。网页资源随 Python 包分发，无需 Node 或前端构建步骤。

## 已提供

- 标定流程：说明左右手眼、顶相机桥接、独立验证，以及可选内参和桌面步骤。
- 接入配置：适配器、设备身份、连接和板规格的空白草稿，可保存和恢复。
- 离线验证：运行合成示例，可选择桌面步骤；也可上传匹配的 rig.json 与 observations.json。
- 标定结果：显示求解状态、失败原因、公共坐标系与独立验证偏差，可下载 JSON 或 ZIP 数据包。

导入数据中的可选步骤以其 rig 配置为准。网页草稿不会覆盖导入配置。
结果下载只导出记录，不会替换已安装标定；正式发布仍通过 CLI 的 publish 入口完成。
已保存的任务在重启服务后仍可查看。运行中退出的任务会标记为中断失败，需重新提交。

## 数据目录

接入草稿为 `integration-draft.json`，每次任务有独立目录和 job.json，成功后生成 run/ 数据包。
本地配置可能包含设备地址，`runs/` 默认被 Git 忽略。使用仓库外的自定义数据目录时，
也应保持其为本机运行数据，不作为项目源码提交。

服务用于本机操作，默认监听 127.0.0.1；尚未提供远程登录和多用户任务管理。
