# 网页工作台

安装后运行：

```bash
dual-arm-calibration web --port 8765 --data-dir runs/web
```

在浏览器打开 `http://127.0.0.1:8765`。网页资源随 Python 包分发，无需 Node 或前端构建步骤。

## 已提供

- 标定流程：说明左右手眼、顶相机桥接、独立验证，以及可选内参和桌面步骤。
- 接入配置：适配器、设备身份、连接和板规格的空白草稿，可保存和恢复。
- 离线验证：运行合成示例，可选择桌面步骤；也可上传匹配的 rig.json 与 observations.json。
- 标定结果：显示求解状态、失败原因、公共坐标系与独立验证偏差，可下载 JSON 或 ZIP 数据包。

导入数据中的可选步骤以其 rig 配置为准。网页草稿不会覆盖导入配置。
结果下载只导出记录，不会替换已安装标定；正式发布仍通过 CLI 的 publish 入口完成。
已保存的任务在重启服务后仍可查看。运行中退出的任务会标记为中断失败，需重新提交。

## 数据目录

接入草稿为 `integration-draft.json`，每次任务有独立目录和 job.json，成功后生成 run/ 数据包。
本地配置可能包含设备地址，`runs/` 默认被 Git 忽略。使用仓库外的自定义数据目录时，
也应保持其为本机运行数据，不作为项目源码提交。

服务用于本机操作，默认监听 127.0.0.1；尚未提供远程登录和多用户任务管理。

## 深度与双目标定（可选）

`--depth-config` 指向本机 JSON，至少包含 `serial` 和与实物核对的 `board`。
默认不加载深度 SDK、不连接相机。可选参数：

- `target_pairs`：30；`min_corners`：12 个左右共同角点。
- `stable_s`：0.25 秒；`stable_rms_px`：左右视图各自相对窗口起点的角点 RMS 位移不超过 1.5 像素，与原有停稳采集规则一致。
- `novelty_px`：相对任一已有样本，共同角点中位位移至少 25 像素。
- `duration_s`：默认 300 秒自动结束；界面显示本轮倒计时及停止原因，停止始终保留已保存样本。
- `camera_service` 与 `camera_status_file`：可选的本机 systemd 用户相机服务及其状态文件。
  状态需有 `wall_time`、`recording`；确认未录像后暂停，结束时恢复。

这些是可调整的采集参数，不是厂家精度保证。调用者负责让机器人静止，并避免其他相机
使用者并发打开设备。驱动放在独立子进程中，停止请求不阻塞网页。默认只监听本机；
局域网监听须由现场显式指定，网页未提供用户认证。

每个采集目录保留配置、左右图、RGB、原生深度、共同角点、帧号和时间戳。
只接收左右帧号相同且时间戳差不超过 1 ms 的 IR 对。该条件不意味着 RGB 硬件同步；
板需停稳。红外小图案可二倍插值辅助检测，角点映射回原始像素坐标。
检测启用 OpenCV 的板结构辅助标记恢复（`tryRefineMarkers`），以恢复远处未直接解码的标记候选；
仍使用共同角点与停稳规则。采集须覆盖实际工作距离，近距离样本不能替代桌面远距离验证。

“继续采集”创建新批次并复制已有样本，原批次保持不变；核对相机、板规格和图像参数后补拍。
去重也包含原有样本。若要在目标已满后补采，请在现场配置中提高 `target_pairs` 后续采。

最少 25 组，其中至少 5 组留出。页面报告跨视图重投影误差、极线残差、基线和候选矩阵。
保留候选而不发布，独立高度验证另做。结果中的视差必须与对应输出分辨率的焦距配套；
二次校正后的点需通过 R1 的逆旋转返回原左相机坐标，再使用外参计算世界高度。
开始或继续采集会启用浏览器提示音，也可单独点击试音；每次保存响两声。刷新后需要重新开启。
声音从访问网页的电脑播放，页面会显示音频暂停状态；系统或网站静音仍需在浏览器端检查。

### 离线拟合红外到 RGB 的外参

`python -m dual_arm_calibration.color_extrinsics --session SESSION --reference METADATA --output NEW_DIRECTORY`
复用采集中的 RGB 图及共同板角点；`METADATA` 显式提供既有 RGB 内参、畸变、世界变换和厂家
`color_from_left`，不得补成设备默认值。固定 RGB 模型和世界基准，仅拟合 IR 到 RGB 的刚体变换。
沿用双目标定训练/留出 ID；独立板高不参与优化。对比已拟合的 IR 模型、相同 K 且残余畸变为零、
厂家 IR 模型，报告正反方向留出投影误差。零畸变分支用于敏感性分析，不是完整双目重标定。

Y8 红外是已校正图像，拟合的畸变仅描述残余修正，不能再次套用原始传感器镜头系数。
目前旧批次未保存 RGB 帧时间戳，IR/RGB 不是硬件同步；停稳采集有助于减小影响，但不能证明
完全同步。输出保持候选状态，需要独立图像、板高验证，不自动写入固件或真机配置。
