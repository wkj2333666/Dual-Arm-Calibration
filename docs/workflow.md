# 双臂三相机统一标定流程

## 配置与初始化

固定结构：左右法兰各安装一台腕相机，另有一台固定顶相机。
左右基座无需预先对齐，机器人无需同品牌或同关节数。
标定板尺寸和字典可配置；示例是 7×5 ChArUco，方格 40 mm、标记 28 mm、DICT_5X5_50。
板必须平整且实测尺寸准确。制造厚度与图案平面到桌面的距离可能不同，应使用后者。

每批数据绑定硬件安装身份、相机序列号、分辨率、旋转方向、参数和板规格。
已有可靠手眼外参时，可由一张图估计板位姿用于规划；这是自动采集适配器的初始化策略。
没有可靠外参时从人工示教采集开始，不能把未验证的单图估计当作安全运动依据。

## 可选相机内参步骤

逐相机选择 `reuse` 或 `fit`。复用也必须声明参数来源并验证与当前图像配置相符。
当前 `fit` 只实现 D435i RGB 专用 radial2：固定厂家 K，仅拟合 k1、k2，p1=p2=k3=0。
不要求不同相机的系数相近；不把该拟合限制推广到其他相机、深度流或红外流。

腕相机移动、板固定；顶相机固定、板移动。覆盖九宫格、四周边缘、不同距离以及两个方向倾角。
至少 20 张有效视图，腕相机建议预采 28 张。录像选帧还检查清晰度与角点位移重复度。
每个九宫格至少 2 张、每个边缘至少 3 张；4 折留出及全量拟合 RMS ≤0.5 px，
全图重采样位移标准差最大值 ≤2 px。阈值来自已验证的项目配置，不是厂家精度声明。

## 手眼与顶相机外参

每侧至少 20 个固定板手眼姿态；一批内板不能移动，两侧之间可重新摆板。
内参和手眼使用不同批次；求手眼时固定相机模型。
必须具有至少两个非平行旋转方向，不可仅平移或只绕单轴。
保留实测法兰位姿；TCP 位姿必须先由适配器转换为法兰位姿。

顶相机与每侧腕相机至少 12 组配对观测，板在组间改变位置、倾角，组内停稳。
各侧独立求 `base_from_top`，不把左右腕标定时不同的板位置当成同一世界坐标。
手眼使用多方法初值与像素重投影优化；顶相机固定腕外参和相机模型后优化。
两者均采用 4 折留出验证，外参拟合及留出重投影 RMS ≤2 px；
手眼板位姿一致性 RMS ≤5 mm、1°。剔除异常数据后数量不足应补采。

## 独立验证与可选桌面

至少 3 组未参与拟合的三相机观测，验证同一块板在顶相机坐标系中的一致性。
当前独立验证要求同时三相机可见；未来若支持分区工作空间，应增加独立的配对验证模式，
不能直接删掉验证要求。每条腕链相对顶相机的最大偏差 ≤5 mm、1°。

桌面步骤可完全跳过，公共坐标系为顶相机，`table.calibrated=false`、高度为 null。
启用时另采至少 3 组固定平放板观测，不与验证批次共用 ID。
声明板 +Z 指向桌面内部还是外部，世界 +Z 统一朝桌面上方，世界 X 沿板 X。
板原点投影到桌面作为世界原点，印刷面高度为正的板厚。
全部帧/相机相对平均板位姿最大偏差 ≤5 mm、1°。

## 结果生命周期

每次 CLI 求解在新目录产生不可覆盖的输入、结果和哈希清单，可按相同输入重算。
`publish` 验证清单与输入/结果绑定后保存旧版并原子替换本地目标文件。
CLI 当前按整个数据集重新求解，不提供持久化逐阶段任务调度。
已完成阶段可通过 Python API 单独计算；正式数据包发布仍必须经过整体验证。

相机更换、安装移动或图像配置改变需重新建立相应标定；腕外参改变后重做依赖它的桥接和验证。
顶相机移动后重做桥接和公共坐标系；仅桌面板重新摆放也会改变桌面原点/轴向。
此流程不自动认证机器人运动学、TCP、碰撞模型或深度相机尺度。
